# Imported island

`google-island.glb` is the complete Island scene by Poly by Google, downloaded
from https://poly.pizza/m/bzLVwG4AzvA (Creative Commons Attribution 3.0):
https://creativecommons.org/licenses/by/3.0/

The original GLB is retained, including its embedded palette texture. Runtime
scale is (0.7, 0.28, 0.7), lowering the steep relief and tall palms visibly; the
exact same transformed vertices supply ground and solid-component collision.
There are no route-only floors or repair-dependent terrain in this layout.
All eight repair IDs are retained and positioned on actual shared ground.
Shipped attribution is in public/licenses/imported-island.txt and the pause menu.
