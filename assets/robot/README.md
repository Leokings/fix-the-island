# Restoration robot

Unmodified `RobotExpressive.glb`, downloaded 2026-10-08 from the Three.js examples:
https://raw.githubusercontent.com/mrdoob/three.js/dev/examples/models/gltf/RobotExpressive/RobotExpressive.glb

Author: Tomás Laulhé / Quaternius. CC0 1.0, as recorded in the upstream README:
https://github.com/mrdoob/three.js/blob/dev/examples/models/gltf/RobotExpressive/README.md
https://creativecommons.org/publicdomain/zero/1.0/

Upstream modifications by Don McCurdy: facial morph targets, FBX2GLTF conversion,
duplicate-material removal and reduced metalness. The game normalizes the actor
to 1.65 m, clones instance materials, and crossfades the original Idle, Walking,
Running and Punch animations through AnimationMixer. No procedural bone poses.
