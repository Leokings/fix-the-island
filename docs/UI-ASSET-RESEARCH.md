# Final UI asset candidate

Research only, checked 2026-10-08. Publish: LOCKED. No font is imported or selected by this note; final UI authoring remains the separately gated C4 work.

Nunito Sans is a candidate for a readable humanist game-control family with a stronger heading weight. The [official Google Fonts metadata](https://github.com/google/fonts/blob/main/ofl/nunitosans/METADATA.pb) identifies its variable-font files and OFL license. The [actual distributed license](https://raw.githubusercontent.com/google/fonts/main/ofl/nunitosans/OFL.txt) permits software bundling and embedding subject to its conditions, including retaining the copyright notice and license and observing the rules for modified fonts. Retain the exact license beside any selected asset, record the downloaded file/hash, and self-host it rather than silently adding a remote font-service dependency.

This is an optional supporting source, not a substitute for authored interface hierarchy, original icons, sufficient text size, contrast or the locked game-HUD criterion. The current placeholder system font is not a final-UI decision. Reference screenshots stay review-only and never enter interface textures or other shipped assets.
